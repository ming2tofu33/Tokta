## 지금 기준 (2026-10-13)

- **서비스:** ChatGPT(Codex 한도), Claude, Grok, Cursor(+Grok Bot). [[00 서비스 목차]]
- **ChatGPT:** 이 Mac의 Codex 로그인으로 실제 값 조회 확인(Pro, Codex 주간). 계정마다 전용 Codex 로그인으로 다중 계정 지원. 사용자가 두 번째 계정 로그인까지 확인.
- **Claude:** 계정별 웹 로그인. 사용자가 실제 계정 로그인까지 마쳤다.
- **Grok:** 공식 Grok CLI 로그인으로 실제 조회 확인(주간). 토큰 갱신은 CLI에 맡긴다. [[Grok]]
- **Cursor:** 계정별 cursor.com 로그인, Cursor 모델·기타 모델·Grok Bot 주간. 사용자 로그인·조회 확인. [[Cursor]]
- **그룹:** 이름을 직접 붙이는 계정 그룹. 사용자 앱 사용 확인.
- **알림:** 20%·5% 한도 임박(다른 계정 추천 포함), 낮았던 구간의 리셋 완료, 메뉴바 아이콘 색. 사용자 알림 수신 확인. [[2026-10-13 한도 임박과 리셋 알림 설계]]
- **소진 예측:** 사용 기록으로 “이 속도면 언제 바닥”을 보여주고 1시간 안이면 알린다. [[2026-10-13 사용 기록과 소진 예측]]
- **구독 관리:** 계정마다 구독료·결제일, 월 합계, 결제 전날 알림. [[2026-10-13 구독료와 결제일 관리]]
- **설치:** `./scripts/install.sh`로 `/Applications`에 설치, 설정에서 로그인 시 열기. [[빌드와 서명#설치해서 쓰기]]
- **코드:** `~/Projects/Tokta` (SwiftUI, macOS 15+). 저장소 `ming2tofu33/Tokta` (MIT 공개).
