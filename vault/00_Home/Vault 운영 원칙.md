# Vault 운영 원칙

1. Obsidian에서 여는 폴더는 저장소 안의 `vault/`다.
2. 코드가 기준이다. vault에는 왜 그렇게 만들었는지, 무엇을 확인했는지를 남기고 코드 내용을 그대로 옮겨 적지 않는다.
3. 결정을 내리면 `01_Logs/Decisions`에 날짜·배경·사용자 결정을 남기고 관련 문서를 고친다. 뒤집힌 결정은 지우지 않고 새 결정을 연결한다.
4. 검증 수준을 섞지 않는다: **코드 작성 / 테스트 통과 / 렌더링 확인 / 이 Mac 실제 조회 / 사용자 앱 사용 확인 / 배포**.
5. 서비스 API는 비공식이라 언제든 바뀐다. 응답 형식을 확인하면 `04_Services` 해당 노트의 확인 이력에 날짜·계정 플랜·방법을 적는다. 수집이 깨지면 `01_Logs/Incidents`에 기록한다.
6. 토큰·쿠키·비밀번호는 vault에 적지 않는다. 계정 이메일도 필요한 경우가 아니면 적지 않는다.
7. 내부 링크는 wikilink로 쓴다. 표 셀 안 별칭 구분자는 `\|`.
8. `.obsidian/workspace*.json`은 개인 화면 상태라 git에 넣지 않는다.
