# 2026-10-13 Claude는 계정별 웹 로그인으로 수집

- 배경: 처음에는 Claude Code CLI가 키체인에 저장한 OAuth 로그인으로 사용량 API를 읽도록 만들었다. 앱 실행 결과 “Claude Code 로그인 정보를 찾지 못했다”. 이 Mac은 Claude 데스크톱 앱 안의 Claude Code만 쓰고, 데스크톱 앱이 로그인을 대신 관리해서 CLI 로그인 정보가 따로 없었다.
- 대안:
  - A. claude.ai 웹 로그인 수집기 — 다중 계정 가능, 데스크톱 앱 사용자도 됨.
  - B. 터미널 Claude Code CLI에 따로 로그인 — 계정 1개만.
  - 데스크톱 앱의 암호화 저장소를 읽는 방법은 다른 앱 저장소를 여는 것이고 업데이트마다 깨질 수 있어 제외.
- 사용자 결정: “A로 해줘”
- 근거: Claude 구독 한도는 claude.ai·데스크톱 앱·Claude Code가 같이 쓰므로 Claude 계정 사용량이 곧 Claude Code 사용량이다.
- 결과: [[Claude]]. 사용자가 같은 날 실제 계정 로그인까지 마쳤다.
- Google 로그인 우려: [[Google 로그인 제약]]
