# 2026-10-13 Grok 추가와 토큰 갱신을 CLI에 맡김

- 배경: 사용자 “그록 유료로 쓰고 잇어”, “커밋하고 그록 작업해줘”.
- 대안:
  - A. 공식 Grok CLI 로그인 토큰으로 xAI 사용량 API — AI-Tracker에서 쓰던 방식, 숫자를 직접 준다.
  - B. grok.com 사용량 페이지 글자 읽기 — 화면 문구가 바뀌면 깨지고, X·Google 로그인은 앱 안 창에서 막힐 수 있다. [[Google 로그인 제약]]
- 결정: A. 서비스 목록에 Grok 추가.
- 토큰 갱신: CLI 토큰은 몇 시간이면 만료된다. AI-Tracker는 직접 OIDC 갱신 후 파일에 다시 썼지만, 갱신 토큰이 바뀌면 동시에 쓰는 CLI 로그인이 풀릴 수 있다. Tokta는 **만료가 가까우면 `grok models`를 실행해 CLI가 스스로 갱신하게** 하고 토큰을 직접 쓰지 않는다. Codex처럼 로그인 관리를 공식 도구에 맡기는 원칙. 이 방법이 실제로 갱신되는지는 만료 후 확인 필요.
- 다중 계정: ChatGPT와 같이 기본 `~/.grok` + 계정별 `GROK_HOME` 전용 폴더(`grok login --oauth`).
- 결과: [[Grok]]. 이 Mac 실제 조회 확인(주간 100% 남음).
