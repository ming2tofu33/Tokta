# 2026-10-13 vault 서비스 카탈로그와 폴더 번호 정리

- 배경: vault를 기본 형식으로 만든 뒤, 이 프로젝트에만 필요한 분류가 있는지 검토했다. Tokta의 가장 큰 위험은 바깥 서비스의 비공식 API가 바뀌어 수집이 깨지는 것이다.
- 사용자 결정: “그래 그리고 숫자도 폴더 숫자도 맞춰줘”
- 결과:
  1. `04_Services` 신설 — 서비스마다 노트 하나(수집 방식, 플랜별 한도 규칙, 응답 확인 이력, 깨짐 기록). `03_Technical`의 ChatGPT·Claude 수집 문서를 [[ChatGPT]]·[[Claude]]로 옮겼다. [[Gemini]]는 미지원 상태로 추가. 목차 [[00 서비스 목차]].
  2. `01_Logs/Incidents` 신설 — [[00 깨짐 기록 목차]], [[깨짐 기록 템플릿]].
  3. 폴더 번호를 빈 번호 없이 이음: `04_Research` → `05_Research`, `08_Assets` → `06_Assets`. Obsidian 첨부 폴더 설정도 바꿨다. 링크는 이름 기준이라 유지된다.
- 만들지 않은 것: 배포·디자인·보안 카테고리는 필요해질 때 추가한다. API 응답 샘플은 코드의 테스트 데이터로 둔다.
