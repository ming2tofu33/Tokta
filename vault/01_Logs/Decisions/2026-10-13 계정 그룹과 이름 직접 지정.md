# 2026-10-13 계정 그룹과 이름 직접 지정

- 배경: 사용자 “혹시 그룹으로 묶고 그룹 이름도 커스텀할 수 있을까?”
- 결정과 동작:
  1. 그룹은 사용자가 이름을 붙이고, ChatGPT·Claude 계정을 섞어 담을 수 있다.
  2. 메뉴는 그룹 순서대로 보인다. 카드마다 서비스 이름을 같이 표시한다. (그룹 안 순서는 아래 후속 결정으로 바뀜)
  3. 그룹에 넣지 않은 계정은 맨 뒤 “그룹 없음”. 그룹이 하나도 없으면 예전처럼 서비스별로 보인다.
  4. 그룹을 지워도 계정은 남는다.
  5. 설정 → 그룹 탭에서 이름을 바로 바꾸고, 끌어서 순서를 바꾼다. 계정 탭에서 계정마다 그룹을 고른다.
  6. “지금 쓰기” 추천은 그룹과 관계없이 서비스 전체 계정 중에서 고른다.
- 결과: 테스트 4건 통과, 렌더링 확인, 사용자 앱 사용 확인.
- 저장: `groups.json`. [[저장 데이터와 이전]]

## 후속 — 계정 순서 끌어서 바꾸기 (같은 날)

- 사용자 “계정 순서 바꿀 수 있게 할 수 있어? 드래그해서 바꿀 수 있게”
- 그룹 안 자동 서비스 정렬을 없애고 **사용자가 정한 계정 순서**를 따른다. 그룹이 없을 때의 서비스별 묶음 안에서도 같다.
- 설정 → 계정 탭을 메뉴와 같은 묶음(그룹 또는 서비스)으로 바꾸고, 묶음 안에서 끌어서 순서를 바꾼다. 다른 그룹으로 옮기는 것은 그룹 선택으로 한다.
- 순서는 `accounts.json`의 계정 순서로 저장된다. 한 묶음 안에서 옮겨도 다른 묶음 계정의 위치는 그대로다.
- 결과: 테스트 통과, 사용자 앱 사용 확인.
