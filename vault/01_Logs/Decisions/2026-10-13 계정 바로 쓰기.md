# 2026-10-13 계정 바로 쓰기

- 배경: 사용자 “내가 생각하는 건 좀 더 유용한 데스크탑 어플이어야 하는데.” Tokta는 계정마다 따로 로그인된 세션(Claude·Cursor는 계정별 WebKit 저장소, ChatGPT·Grok은 계정별 CLI 로그인 폴더)을 이미 갖고 있지만 숫자를 읽는 데만 썼다. “서브2를 쓰세요”라고 알려줘도 실제로 바꾸려면 브라우저에서 로그아웃·로그인을 해야 했다([[앱 구조#카드와 메뉴바]]의 한계).
- 대안: 계정 바로 쓰기 / 큰 대시보드 창 / 항상 떠 있는 HUD / 구독 활용도 먼저.
- 사용자 결정: “계정 바로 쓰기”.
- 동작:
  1. **Claude·Cursor**: 그 계정 저장소로 로그인된 Tokta 창(`AccountWindowController`)을 연다. 계정마다 창 하나, 같은 서비스 창은 조금씩 비켜 놓는다.
     - 위쪽 막대: 계정 이름 · 막대 · 남은 % · (걸리는 일 또는 리셋까지) · 계정 바꾸기 메뉴 · 새로고침.
     - 빠듯하거나(알림 기준선 아래, 다 씀, 소진 예측, 오래된 값) 오류가 있으면 “서브2 계정으로 바꾸기 · 70%” 버튼을 크게. 누르면 같은 자리·크기로 그 계정 창을 열고 이 창은 닫는다. 추천 기준은 메뉴와 같다.
     - 새 창 링크: 같은 서비스면 그 창에서, 다른 사이트면 기본 브라우저. 파일 첨부(열기 패널), 다운로드(~/Downloads, 같은 이름이면 번호, 끝나면 Finder에서 보여줌).
     - 메뉴바 앱이라 편집 메뉴가 없어서 ⌘C·⌘V·⌘X·⌘A·⌘Z·⇧⌘Z·⌘R·⌘W를 웹 보기에서 직접 처리한다.
     - 계정을 지우면 창을 닫는다(저장소도 지워지므로).
  2. **ChatGPT·Grok**: 그 계정 로그인 폴더(`CODEX_HOME`·`GROK_HOME`, 기본 로그인 계정은 지정 안 함)로 공식 CLI를 터미널에서 실행한다. `~/Library/Application Support/Tokta/launch/<계정 ID>.command`를 만들어 연다. CLI를 끝내도 같은 환경의 셸이 남는다. 값은 작은따옴표로 감싸 셸이 해석하지 않게 한다.
  3. 들어가는 곳: 펼친 화면의 “이 계정으로 열기”(Codex·Grok CLI는 문구가 다름) 버튼, 오른쪽 클릭 메뉴 맨 위. 브라우저로 여는 링크는 “브라우저에서 열기”로 이름을 바꿔 남겼다.
- 한계:
  - Claude 데스크톱 앱·ChatGPT 데스크톱 앱 자체의 계정은 바꿀 수 없다. ChatGPT·Grok 웹은 Tokta가 웹 로그인을 갖고 있지 않아 CLI만.
  - Tokta 창 안에서는 Google 로그인이 막힌다(로그인 창과 같음). 이미 로그인된 계정은 상관없다.
  - 웹 알림, 마이크·카메라 권한 요청은 처리하지 않는다.
- 결과: 코드 `Tokta/UI/AccountWindow.swift`, `UI/AccountOpen.swift`, `Providers/TerminalLaunch.swift`, `UsageStore.bestAlternative`. 전체 테스트 통과(91개, 터미널 스크립트·따옴표·다운로드 이름 포함), 위쪽 막대 렌더링 확인. **실제 창 열기·터미널 실행은 사용자 확인 전.**
