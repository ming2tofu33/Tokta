# 2026-10-13 구독료와 결제일 관리

- 배경: 사용자 “구독료 갱신일 관리 기능 해줘”. 계정이 많을수록 매달 AI 구독에 얼마 쓰는지, 언제 결제되는지 알기 어렵다. Electron 버전에도 요금·주기 항목이 있었다.
- 결정과 동작:
  1. 계정마다 **금액·통화(USD·KRW)·주기(매월·매년)·결제일 하나**를 적는다. 지난 결제일이든 다음 결제일이든 하나만 넣으면 다음 결제일을 계산한다. 1월 31일처럼 짧은 달에 없는 날은 그달 마지막 날로.
  2. **설정 → 구독 탭**: 모든 계정을 다음 결제가 가까운 순으로 보여주고 입력·수정·지우기. 아래에 **월 합계**.
  3. 월 합계는 매년 결제를 12로 나눠 더하고, **통화가 다르면 환율 없이 따로** 보여준다(“$220 · ₩29,000”).
  4. 메뉴: 카드에 “$300/월 · 10월 18일 결제 (D-5)”(오늘·내일은 “오늘 결제”·“내일 결제”), 아래쪽에 “월 구독 …” 합계.
  5. **결제 전날 오전 9시 알림** — “내일 $300 결제 예정 (매월)”. 설정 → 알림에서 끌 수 있다(기본 켬). 전날 9시가 이미 지났으면 그다음 결제를 예약한다.
  6. 플랜별 가격을 미리 채워두지 않는다. 가격이 자주 바뀌고 지역·세금에 따라 달라서 직접 입력이 정확하다.

## 후속 — 결제일 자동으로 가져오기 (같은 날)

- 사용자 “구독일을 우리가 가져올 수는 없는 거지?” → 서비스별로 확인 후 “응 그렇게 진행해줘”.
- **Claude**: `GET /api/organizations/{조직}/subscription_details`의 `next_charge_date`·`billing_interval`·`currency`·`status`·`plan_ending_at`. 카드 정보는 읽지 않는다. 2026-10-13 실제 계정 2개에서 다음 결제일 확인. [[Claude]]
- **Cursor**: 사용량 응답의 `billingCycleEnd`를 다음 결제일로 본다(월 구독 기준). 실제 계정에서 확인. [[Cursor]]
- **ChatGPT**: Codex 연결은 결제일을 주지 않는다. 토큰 안에 있을 수 있지만 토큰을 직접 열지 않는 원칙이라 직접 입력. **Grok**: 받는 기간은 주간 사용량 기간이라 결제일이 아니다. 직접 입력.
- 직접 적은 결제일이 가져온 값보다 우선한다. 입력 창에서 Claude·Cursor는 “결제일을 서비스에서 가져오기”가 기본이고, 끄면 직접 지정. 금액은 여전히 직접 입력.
- 금액을 안 적어도 가져온 결제일은 카드·구독 탭에 보이고 결제 전날 알림(“내일 결제 예정”)도 간다. 해지해서 끝나는 구독은 “구독 종료”로 표시하고 알림을 보내지 않는다.

## 후속 — Team 멤버 계정과 조직 결제일 (같은 날)

- 사용자 “클로드는 내가 아까 결제일 넣어둔 거 때문에 우연히 된 것 같은데? 다른 계정들은 안돼.”
- 확인: Claude 계정 5개가 **모두 같은 Team 조직**. 소유자 2개(`owner`, `primary_owner`)만 `subscription_details`를 볼 수 있고, 일반 멤버 3개(`user`)는 **403 permission_error**. 처음 확인은 소유자 계정만 해서 놓쳤다.
- 결정:
  1. 결제일은 조직 단위로 본다. 멤버 계정은 **같은 조직의 다른 계정이 가져온 결제일을 같이 쓴다**(`UsageStore.detectedBilling`). 소유자 계정이 Tokta에 없으면 멤버만으로는 못 가져온다 → 직접 입력.
  2. 결제 전날 알림은 **조직마다 한 번**(금액을 적은 계정 먼저). 같은 조직 5개 계정에 5번 가지 않게.
  3. Team 요금은 조직이 한 번 내므로 **금액은 한 계정에만** 적도록 구독 탭에 안내. 모든 계정에 적으면 월 합계가 겹쳐 더해진다.
- 결과: 실제 5개 계정 모두 같은 다음 결제일 표시(멤버 3개는 소유자 값). 테스트 통과.

- 저장: `accounts.json`의 계정마다 `subscription`. 예전 계정 데이터는 구독 없음으로 읽힌다.
- 결과: 코드 `Tokta/Core/Subscription.swift`(`DetectedBilling`, `Renewal`), `Alerts.swift`(`planRenewals`), `UI/SubscriptionsSettingsView.swift`. 테스트 통과, 카드 렌더링, Claude·Cursor 결제일 실제 조회 확인. 앱 사용 확인 전.
