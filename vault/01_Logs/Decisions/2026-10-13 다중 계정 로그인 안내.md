# 2026-10-13 다중 계정 로그인 안내

- 배경: 사용자가 Google로 가입한 Claude 개인 계정을 Tokta 로그인 창에서 Google로 로그인하려다 막혔고, 같은 Gmail 주소로 이메일 로그인해서 성공했다. 이어서 “다계정을 쓰는 사람은 구글로 말고 이메일로 로그인을 해야 한다는 안내를 어디에 추가해야할까? 챗지피티도?” → 네 가지 모두 진행.
- 서비스별 사정: Claude·Cursor는 Tokta 안 창이라 Google 로그인이 막힌다. ChatGPT·Grok은 평소 브라우저에서 공식 로그인을 하므로 Google 로그인은 되지만, **브라우저에 이미 로그인된 다른 계정으로 연결될 수 있다.** [[Google 로그인 제약]]
- 결정:
  1. **Claude·Cursor 로그인 창이 Google 로그인 페이지로 가는 순간** 주황 안내와 “처음으로 돌아가기” 버튼을 크게 띄운다(Claude: 같은 Gmail로 ‘이메일로 계속하기’, Cursor: GitHub·이메일).
  2. **설정 → 계정 추가 줄 아래**에 고른 서비스의 로그인 주의점을 한 줄로 보여준다.
  3. **ChatGPT·Grok 로그인 대기 중** “추가할 계정으로 로그인하세요” + “다른 계정이 이미 로그인돼 있으면… 로그아웃하거나 시크릿 창”. ChatGPT는 **로그인 주소 복사** 버튼으로 시크릿 창에 붙여넣을 수 있다(Grok은 CLI가 주소를 직접 열어 Tokta가 주소를 모른다).
  4. **같은 계정 두 번 추가 경고**: 같은 서비스에서 먼저 추가한 계정과 로그인 이메일이 같으면 나중 계정에 “이미 추가된 계정(…)과 같은 계정입니다. 다른 계정으로 다시 로그인하세요”. 숫자는 그대로 보여준다.
- 후속(같은 날): 사용자 “코덱스랑 그록 꼭 넣어놔야해?” → 설명 후 “앱이 깔려 있어야 한다는 조건을 알려주면 더 좋을 거 같네”.
  - ChatGPT는 **ChatGPT 데스크톱 앱**(안에 든 Codex), Grok은 **Grok CLI**가 설치돼 있어야 한다. 직접 쓰거나 로그인해 둘 필요는 없다. “이 Mac 로그인 연결”은 이미 된 로그인을 빌려 쓰는 지름길일 뿐 필수가 아니다.
  - 설정 → 계정에서 ChatGPT·Grok을 고르면 필요한 프로그램과 설치 여부(✓ 설치됨 / 주황 경고 + 다운로드 링크)를 보여주고, 설치 안 됐으면 추가 버튼을 막는다. “이 Mac 로그인 연결”의 해당 항목도 막는다. 카드 오류도 “ChatGPT 데스크톱 앱이 설치돼 있지 않습니다…”로 바꿨다. 코드 `Tokta/Providers/RequiredApps.swift`.
  - 프로그램 없이 쓰려면 ChatGPT·Grok도 웹 로그인 방식으로 바꿔야 한다(응답 형식 미확인) — 보류.
- 결과: 테스트 통과, 카드 렌더링 확인. 앱 사용 확인 전.
