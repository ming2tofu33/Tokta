# 2026-10-13 앱 아이콘과 메뉴바 아이콘 v1

- 배경: 남은 작업 “앱 아이콘”. 다른 세션이 만들었고, 사용자가 끝난 작업이라고 확인했다.
- 결과:
  - **메뉴바 아이콘**: 단색 토큰 — 원에 대각선 홈, 아래쪽에 한도 조각을 따로 떼어낸 모양. 18pt 기준, 라이트·다크 모두 템플릿 이미지로 메뉴바 색을 따른다. `Assets.xcassets/ToktaMenu.imageset`. 기존 SF Symbol 계기판 아이콘을 대체했다.
  - 경고 상태 색(주황·빨강)은 [[2026-10-13 한도 임박과 리셋 알림 설계]]대로 유지 — 같은 모양을 그 색으로 채운다(`MenuBarIcon.swift`).
  - **앱 아이콘**: `Assets.xcassets/AppIcon.appiconset` (16~512pt, 1x·2x). Xcode 설정 `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`.
  - 원본과 생성 스크립트: `design/menu-bar-v1/` (`generate.swift`, SVG, 미리보기 `preview.png`, `ToktaGlassMaster.png`).
- 커밋 경위: 이 작업은 따로 커밋되지 않았고, 소진 예측 커밋 `bf9c50c`에 **실수로 함께 들어갔다**(변경 파일을 확인하지 않고 전부 담음). 빌드·전체 테스트 통과를 확인했고, 사용자 확인 후 기록을 고쳐 쓰지 않고 그대로 두기로 했다. 이후 커밋은 변경 파일을 확인하고 해당 작업 파일만 담는다.
