# 2026-10-14 Gemini 단일 계정 연결

- 배경: 결정 대기 “Gemini 추가 여부와 시점”. 사용자 “제미나이도 다계정은 어렵더라도 일단 단일 계정 연결시키자”.
- 결정: Gemini CLI 로그인 하나로 Gemini CLI·Code Assist 한도를 읽는다. 앱 채팅 한도는 숫자가 없어서 이것으로 대신한다(ChatGPT = Codex 한도와 같은 방식).
- 왜 이 방식: CLI가 시스템 브라우저로 로그인해서 [[Google 로그인 제약]]을 피한다. Chrome 확장 다리는 설치 부담이 크다.
- 토큰 갱신은 하지 않는다. 만료되면 Gemini CLI를 한 번 실행하라고 안내한다. 불편하면 메모리에서만 갱신하는 방법을 다시 검토 → [[Gemini#결정할 것]].
- 계정 하나만: 설정 계정 추가 목록에는 빼고 “이 Mac 로그인 연결”로만 추가(`Service.supportsMultipleAccounts`, `hasSystemLogin`). “Gemini CLI 열기”는 터미널에서 `gemini` 실행.
- 결과: [[Gemini]]. 테스트 통과(96개). **이 Mac에 Gemini CLI가 없어 실제 조회 확인 전.**

## 후속 — CLI 찾는 위치 (같은 날)

- 사용자가 `npm install -g @google/gemini-cli`로 설치하자 `~/.local/node/bin/gemini`에 생겼다(npm 전역 위치를 바꿔둔 환경, Node는 mise). Tokta가 찾는 고정 위치에 없어서 못 찾을 뻔했다.
- 결정: 고정 위치(mise·asdf shims 추가)에 더해, 앱이 처음 필요할 때 **사용자 로그인 셸에 PATH를 한 번 물어**(`$SHELL -l -c`, 2초 제한) 그 경로도 찾는다(`Executables.loginShellPath`). 터미널에서 실행되는 CLI는 Tokta도 찾는다. Codex·Grok CLI 찾기에도 같이 적용된다.
- 확인: 빈 환경으로 띄운 로그인 셸 PATH에 `~/.local/node/bin`이 들어 있음. 테스트 통과(98개).
- 참고: 설치 때 npm이 `@github/keytar`·`node-pty`의 설치 스크립트를 막았다. keytar가 없으면 Gemini CLI는 로그인을 키체인 대신 `~/.gemini/oauth_creds.json` 파일에 둘 것으로 보이며, Tokta는 그 파일을 읽는다. 로그인 후 파일이 생기는지 확인 필요.

## 후속 — 무료 개인 계정은 Gemini CLI 지원 종료 (같은 날)

- 사용자 계정(Gemini 구독 없음)으로 Gemini CLI에 로그인은 됐지만 첫 사용에서 “This client is no longer supported for Gemini Code Assist for individuals … migrate to the Antigravity suite” 오류. Tokta에서도 숫자가 들어오지 않았다(사용 기록 없음).
- 즉 이 방식은 **무료 개인 계정에서는 막혔다.** 유료(Google AI Pro·Ultra)나 회사(Code Assist Standard) 계정에서 되는지는 확인 전.
- 오류 문구를 Google이 보낸 이유(`reasonMessage`)를 붙여 “무료 개인 계정은 지원이 끝났어요”로 바꿨다.
- 다음 방향: 사용자 “Antigravity 조사”.

## 후속 — Antigravity로 대체 (같은 날)

- 조사: Google 릴리스 노트상 2026-06-18부터 **모든 개인 등급(무료·AI Pro·AI Ultra)**의 Gemini CLI·Code Assist 요청을 받지 않는다. 회사(Code Assist Standard·Enterprise)·유료 API 키만 남았다. 그러니 Gemini CLI 방식은 개인에게 쓸모가 없다.
- 방법 검토: (1) Antigravity CLI `agy -p /usage --output-format json` (2) 실행 중인 Antigravity 앱 내부 서버 `GetUserStatus`(포트·CSRF 토큰 찾기) (3) Google OAuth 클라우드 API(다른 앱의 OAuth 클라이언트 필요). → **(1)**: 공식 CLI에 묻고 토큰을 건드리지 않는 원칙에 맞고, 모델에 묻지 않아 한도를 쓰지 않는다.
- 이번에는 실제 응답부터 봤다: 사용자가 agy 설치·로그인 → 출력 확인 → 그 형식대로 작성 → Tokta 수집기로 실제 조회까지 확인.
- 사용자 “그럼 제미나이 없애고 안티그래비티만 남기나?” → 서비스 이름을 **Antigravity**로. 한도가 Gemini 앱 한도가 아니고 Claude·GPT 그룹도 들어 있어 “Gemini”는 오해를 부른다. 이미 추가한 Gemini 계정은 Antigravity로 자동 이전(`Service` 디코딩).
- Gemini CLI 수집기(`GeminiProvider`)는 커밋 전에 지웠다. 함께 만든 CLI 찾기 개선(로그인 셸 PATH)은 남겼다.
- 결과: [[Antigravity]]. 테스트 통과(98개, 실제 응답 포함).
