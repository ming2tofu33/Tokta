# 2026-10-14 픽셀 캐릭터

- 배경: 사용자 “Tokta를 조금 더 특별하게 만들 수 있을 방법이 없을까? 캐릭터를 더한다거나…” → 캐릭터가 곧 게이지인 방향 제안 → “픽셀로 작업할 수도 있어?”
- 시안 경과(모두 `design/`, 생성 스크립트 `sprites.py` 포함. v1~v4는 2026-10-17 공개 전 정리로 지움):
  - v1 새싹 토큰·동전·칩 → “C(칩)가 그나마 괜찮은데 다른 스타일 없을까?”
  - v2 칩·배터리·터미널·로봇·젤리·쿠키 → “칩, 배터리, 터미널 귀여운 거 같아. 좀 더 디테일하게”
  - v3 32×32 음영·볼·깜빡임 → “좀 더 심플했을 때가 예뻤던 거 같아. 터미널 버전 여러 버전”
  - v4 16×16 터미널 6종(모니터·노트북·맥 창·맥 창+글자 얼굴·CRT·화면만) → “T4 괜찮아 보인다”
  - v5 T4 다듬음 → “괜찮은 거 같아”
- 결정: **v5 — 맥 창(신호등 버튼) + 글자 얼굴, 16×16, 평평한 색.** `design/pixel-character-v5/`
  - 화면이 아래부터 빛으로 찬 높이 = 남은 한도. 색은 사용량 색 조합을 따른다.
  - 얼굴(이모티콘): 여유 `^_^` · 보통 `•_•` · 빠듯 `>_<`+땀방울 · 다 씀 `-_-`+Z(화면 안) · 리셋 `^o^`+반짝임. `-_-`(시큰둥)·`> <`(힘듦)으로 읽히는 얼굴은 피했다.
  - 움직임: 눈 깜빡임, 커서 깜빡임, 리셋 때 화면이 아래부터 네 단계로 차오름.
  - 큰 크기는 따로 그리지 않고 정수배(2배·4배)로 키운다.
- 넣을 순서(제안): 메뉴 맨 위 카드(링 자리) → 작은 위젯 → 메뉴바 아이콘(지금 아이콘과 고르는 옵션) → 리셋 알림 말투. 메뉴 카드는 다른 세션 작업이 끝난 뒤.
- 결과: 시안 확정.

## 후속 — 앱에 넣음 (같은 날)

- 사용자 “그 순서로 진행해줘”(캐릭터 → 영어 지원).
- 그림: `Shared/PixelCharacter.swift`의 `PixelSprite`가 v5 스크립트와 같은 16x16을 코드로 찍는다. 앱·위젯·메뉴바가 이 하나를 쓴다. 다크 모드에서는 창 테두리·화면을 조금 밝힌다.
- 표정 고르기(`CharacterMood.of`, `Core/CharacterMoodRules.swift`): 못 읽음·오류·오래된 값 → •_• / 다 씀 → -_- / **최근 30분 안에 리셋** → ^o^ / 알림 기준선 아래 또는 1시간 안 소진 예측 → >_< / 절반 넘게 남음 → ^_^ / 그 밖 •_•. 리셋은 사용 기록에서 사용 비율이 뚝 떨어진 시각(`UsageHistory.lastReset`)으로 안다.
- 들어간 곳:
  1. **메뉴 맨 위 카드**: 링 자리에 캐릭터(3배, 48pt)와 아래 %. 커서·눈 깜빡임, ^o^일 때 처음 1초 화면이 차오름. 움직임 줄이기 설정이면 멈춘 그림.
  2. **작은 위젯**: 계정 이름 옆에 캐릭터(움직이지 않음). 앱이 표정을 위젯 파일(`WidgetData.Row.mood`)에 넣어 둔다.
  3. **메뉴바**: 설정 → 일반 → “메뉴바 아이콘을 캐릭터로”(기본 끔). 메뉴바 숫자와 같은 값으로 1픽셀 = 1pt.
  4. **알림**: 한도 임박 `>_<`(다 쓰면 `-_-`), 소진 예측 `>_<`, 리셋 `^o^`를 문구 앞에. 결제 알림은 그대로.
- 결과: 전체 테스트 통과(117개, 표정 규칙·리셋 찾기·그림 칸 포함). 렌더링 확인: 메뉴 카드(라이트·다크), 메뉴바 다섯 표정(라이트·다크), 작은 위젯(라이트·다크). **앱 사용 확인 전.**
