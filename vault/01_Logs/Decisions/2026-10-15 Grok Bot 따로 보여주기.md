# 2026-10-15 Grok Bot 따로 보여주기

- 배경: 사용자 “그록 그록봇 usage는 따로 있을텐데 지금 안 보여주지?” — Grok Bot 주간은 Cursor 계정 줄의 세 번째 막대로만 있어서(이름은 펼쳐야 보임) 없는 것처럼 보였다. 또 Cursor 계정의 가장 빠듯한 구간에 섞여, Grok Bot을 다 쓰면 Cursor까지 빠듯해 보였다(추천·메뉴 카드·위젯·메뉴바·캐릭터 표정). [[2026-10-13 Cursor 추가와 Grok Bot을 Cursor 계정에서 읽기]]에서 “불편하면 나누기”로 남겨 둔 일.
- 결정: **Grok Bot을 독립 서비스로**(`Service.grokBot`).
  1. Grok Bot 계정은 Cursor 계정에 딸린다(`Account.linkedAccountID`). 그 Cursor 계정의 cursor.com 로그인으로 읽어서 따로 로그인하지 않는다(`GrokBotProvider`).
  2. **저절로 생긴다**: Cursor 계정을 읽을 때 Grok Bot 한도가 보이면(`UsageSnapshot.hasGrokBot`) 같은 이름·같은 그룹의 Grok Bot 계정을 하나 만든다. 설정 계정 추가 목록에는 없다.
  3. Grok Bot 계정을 지우면 Cursor 계정에 표시해 두고(`hidesGrokBot`) 다시 만들지 않는다. Cursor 계정을 지우면 딸린 Grok Bot도 지운다.
  4. Cursor 계정에는 Cursor 모델·기타 모델만. Grok Bot 구간 이름은 서비스 이름이 줄에 있으니 “주간”/“체험”.
  5. “Grok Bot 열기”는 Grok Bot 앱(`com.anysphere.sand`)을 연다. 앱이 없으면 cursor.com 대시보드. 다시 로그인은 연결된 Cursor 로그인 창.
  6. 작은 위젯 서비스 고르기에도 Grok Bot 추가.
- 결과: 전체 테스트 통과(122개 — 자동 생성·중복 안 함·지우면 다시 안 생김·Cursor와 함께 지움). Grok Bot 수집기 실제 조회 확인(주간 92%, 2026-10-19 00:33 KST 리셋). **앱 사용 확인 전.** 옛 Cursor 기록의 `grok_bot` 구간은 8일 뒤 저절로 사라진다.
