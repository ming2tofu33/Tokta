# 2026-10-16 디자인 v2와 Tokta 창

- 배경: 사용자 “아직 앱으로서 뭔가 많이 부족하다고 느껴져” → 진단(처음 5분이 거침 · 모은 기록을 안 보여줌 · 믿음 확인 부족 · 디자인) → 사용자 “세 가지 모두와 디자인에서 부족하다고 느꼈어”.
- 순서: ① 디자인 방향 ② Tokta 창(처음 실행 안내 + 이번 달) ③ 메뉴·위젯·iPhone을 새 디자인으로 ④ 믿음(깨졌을 때 화면, 자동 업데이트, 실제 사용 확인).
- 디자인: 세 방향 시안(`design/app-direction-v1`(공개 전 정리로 지움) — A 픽셀 콘솔, B 차분한 유리, C 장부) → 사용자 “b랑 c 살짝 섞은 느낌?” → `design/app-direction-v2` 승인(“좋은 거 같아”).
  - B: 맥다운 바탕, 링, 서비스 색 아이콘, 둥근 카드. C: 맨 위 한 문장, 계정마다 추이 선, 해석 문장(“Tokta가 본 것”).
  - 한 문장 제목은 처음에 세리프(New York·나눔명조)였다가 사용자 “글씨체 좀 별로야. 기본이 나은 거 같아” → **기본 글꼴(semibold)**.
- 만든 것:
  1. **요약 기록**(`UsageLedger`, `ledger.json`): 자세한 기록은 8일만 두므로, 주기가 끝날 때 그 주기 최고 사용 비율과 바닥난 순간만 400일 남긴다. 처음엔 남아 있는 8일 기록으로 채운다.
  2. **Tokta 창**(`Window` id `main`, 메뉴 “Tokta 열기” ⌘O, `tokta://window`):
     - 처음 실행: 계정이 없으면 앱이 이 창을 연다. 서비스마다 연결됨 / 연결(이 Mac 로그인 · Tokta 창 로그인) / 설치 필요 → 다음 단계에서 알림 받을 곳. 이미 계정이 있던 설치본은 건너뛴다.
     - 이번 달(`MonthReport`): 한 문장 요약, 이번 달 구독료·한도가 바닥난 횟수(지난달 기록이 다 있을 때만 비교)·거의 안 쓰는 구독, 구독 가치(계정마다 구간별 주기 최고 사용 비율 평균 중 가장 높은 값), Tokta가 본 것(자주 바닥나는 요일·시간과 바꿔 쓸 계정, 해지하면 아낄 금액, 다음 결제).
     - 기준: 기록 3일 미만이면 “모으는 중”. 거의 안 씀 = 기록 7일 이상 + 최근 14일 최고 사용 10% 미만. 꽉 차게 씀 = 80% 이상. 패턴 = 최근 30일 바닥 3번 이상, 같은 요일 2번 이상.
  3. **메뉴**: 맨 위 한 문장(카드와 같은 계정 + 1시간 안에 바닥날 계정은 주황), 카드는 캐릭터 대신 링, 줄마다 서비스 아이콘 + 최근 7일 추이 선(리셋이 가장 먼 구간, 1시간 넘게 쌓이기 전에는 막대), 아래 “이번 달 $… · Tokta 열기 · 설정 · 종료”, 빈 메뉴는 캐릭터 + “연결하기”.
  - 문장 속 계정 이름 뒤 조사(은/는, 이/가)는 받침으로 고른다(`Josa`). 영어 번역은 조사 인자를 건너뛴다.
- 캐릭터: 메뉴 카드에서는 링으로 바꿨고, 처음 실행·빈 메뉴·메뉴바 아이콘 옵션·위젯·알림 얼굴에 남는다.
- 결과: 맥 테스트 통과(요약 기록·이번 달·조사·한 문장 테스트 추가). 설치본에서 Tokta 창 확인(사용자 실제 계정 — 기록 3일 전이라 “모으는 중”). 메뉴는 예시 데이터 렌더링으로 확인. **처음 실행 화면은 실제 앱에서 확인 전**(이미 계정이 있어 건너뜀).
- 남은 것: ③ 위젯·iPhone을 v2로 ④ 믿음.

## 후속 — 메뉴는 예전처럼 (같은 날)

- 사용자 “이전처럼 남은 사용량을 한 눈에 보는 게 더 나았던 거 같은데. 분석이나 이런건 다른 창에 만들거나 하는게 맞을 거 같아”.
- 결정: **메뉴는 남은 한도를 한눈에 보는 곳, 분석은 Tokta 창.** 메뉴의 한 문장·링·서비스 아이콘·추이 선을 빼고 예전 메뉴(캐릭터 카드 + 구간별 막대)로 되돌렸다.
- 메뉴에 남긴 것: 아래 “이번 달 보기”(⌘O, Tokta 창), 이번 달 구독료 합계, 빈 메뉴의 “연결하기”(처음 실행 안내), 확인이 필요한 계정이 있으면 머리줄의 주황 느낌표.
