# 2026-10-17 오픈소스 공개 (MIT)

- 배경: 사용자 “톡타를 판매하는 건 어렵다고 판단했어” — 계정을 여러 개 구독하는 헤비 개발자는 직접 만들 수 있고, 여러 서비스의 로그인 세션을 다루는 앱이라 판매하면 보안 책임이 크다. 비공식 경로로 사용량을 읽어서 서비스가 바뀌면 바로 깨지는 유지보수 부담도 있다.

- [ ] **지금 저장소를 그대로 공개** — 사용자(2026-10-17): “그냥 지금 레포에서 쓰면 안돼? vault 는 없어야 할 내용들만 없애고?” → 새 저장소는 만들지 않는다. 지운 내용이 예전 커밋에 남아 있으므로 공개 전에 히스토리를 정리한다(force push).
  - 방법은 사용자 확인 후 정한다: 한 커밋으로 합치기 / `git filter-repo`로 지운 노트·문구·이메일만 걷어내기.
