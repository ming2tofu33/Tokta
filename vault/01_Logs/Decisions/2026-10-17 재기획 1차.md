# 2026-10-17 재기획 1차

- 배경: [[핵심 기능과 화면 재기획 2026-10]] → 사용자 결정: 신규 알림 기본 **Mac**, 메뉴 계정 목록은 **지금처럼 모두 펼침**, **커밋(`3504e0f`) 후 1차 시작**.
- 넣은 것:
  1. **기준 계정**(`NowPick`): 고정한 계정 → (고정한 서비스나 마지막으로 연 서비스 안에서) **Tokta로 마지막으로 연 계정**(`lastOpenedAccounts`) → 그 서비스 첫 계정. 숫자가 바뀌어도 기준 계정은 그대로. 카드에 “고정한 계정 / 최근 연 계정 / 기준 계정”.
  2. **대안**: 기준 계정이 경고선 이하·1시간 안 소진·쓸 수 없을 때만, **같은 서비스·같은 그룹**에서, 오류·오래된 값·조회 전 제외, **10%p 넘게** 넉넉할 때(막혔으면 차이 없이, 빠듯하면 “이 계정도 빠듯해요”). 다른 서비스로는 바꾸지 않음. 문구 “같은 그룹의 보조 계정이 더 여유 있어요 · 세션 78% · 주간 61%” + “보조 계정으로 열기”.
  3. **1계정에도 카드**(목록은 생략). 카드에 구간마다 “세션 12% 남음 · 41분 후 리셋”, 확인 시각, 다음 리셋이 다른 구간에 막히면 “…한도 때문에 계속 제한될 수 있어요”.
  4. **메뉴바 숫자·색 = 기준 계정**의 가장 빠듯한 구간. 값 없음·오래됨·오류면 “—”.
  5. **Tokta 창 탭**: 기본 “전체 계정”(서비스·그룹·정렬[내 순서/여유 많은 순/리셋 빠른 순], 구간별 열 “12% · 42분 후” + 막대, 확인 시각, 열기/다시 로그인/새로고침, 칸은 확인 필요·조회 전·해당 없음·이전 값 구분, 줄을 누르면 상세: 구간·리셋 시각·확인 시각·최근 7일 추이(1시간 넘게 빈 곳은 끊음)·구독, “오늘 하루 기록”은 이 탭 아래로). “이번 달” 탭(결제 알림 버튼·메뉴 “이번 달”로 바로). 메뉴 아래 “전체 계정(⌘O) · 이번 달”.
  6. **이름 Codex**(화면만, 저장 id `chatgpt` 그대로).
  7. **처음 실행**: Claude·Codex·Cursor 먼저, Grok·Antigravity는 “다른 서비스”. 이름 입력 없이 “계정 1”로 바로 로그인. 계정마다 로그인 기다림 → 처음 읽는 중 → **N% 남음(성공)** / 실패 “다시 시도·나중에”. **처음 읽기에 성공해야** 다음으로. 알림 단계는 “이 맥(추천)” 먼저, “나중에” 가능.
  8. **알림 기본 Mac**(새 설정만, 저장된 설정 유지). 리셋 예약 알림 문구 “5시간 한도 리셋 예정 시각이에요”(확인 전이라 “다시 채워졌어요”라고 하지 않음).
  9. **iPhone·위젯**: 리셋 예정 시각이 지났을 뿐인 값은 숫자 대신 **“확인 필요”**, 추정값으로는 추천하지 않음. iPhone 큰 추천 카드 제거, 제목 “계정 현황”, “맥이 꺼져 있어요” 대신 “새 값이 아직 도착하지 않았어요”.
- 결과: 맥 테스트 통과(기준 계정·같은 그룹·10%p·막힘·1계정·추정 미추천 테스트). 맥·iPhone 설치. 확인: Tokta 창 전체 계정(실제 Codex 2계정), iPhone 실제 화면, 메뉴는 예시 데이터 렌더링(Claude 5계정·고정 계정 빠듯 → 대안).
