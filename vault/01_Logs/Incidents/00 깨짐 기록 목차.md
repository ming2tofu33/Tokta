# 00 깨짐 기록 목차

서비스 쪽 변경이나 환경 문제로 사용량을 못 읽게 된 일을 기록한다. 파일 이름은 `YYYY-MM-DD 서비스 증상.md`, 양식은 [[깨짐 기록 템플릿]].

## 기록 기준

- 앱이 틀린 숫자를 보여주거나, 오류가 30분 넘게 계속되면 기록한다.
- 증상 → 원인 → 수정 → 확인 순서로 쓰고, 확인 수준([[Vault 운영 원칙]] 4번)을 적는다.
- 서비스 노트([[00 서비스 목차]])의 “응답 형식 확인 이력”과 “깨짐 기록”에도 연결한다.
