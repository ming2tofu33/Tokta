# 빌드와 서명

## Xcode

- 프로젝트: `Tokta.xcodeproj` (Xcode 27, 폴더 동기화 그룹 방식이라 파일을 추가하면 자동으로 포함된다)
- 타깃: `Tokta`(앱), `ToktaTests`(Swift Testing)
- 실행: 스킴 Tokta, My Mac, ⌘R → 메뉴바에 계기판 아이콘
- 서명: 팀 ID는 `Config/Local.xcconfig`의 `DEVELOPMENT_TEAM`(git에 안 올라감), 자동 서명, Hardened Runtime. 팀이 없으면 로컬 서명으로 Mac 앱만 돈다.

## 설치해서 쓰기

매일 쓰는 앱은 Xcode 실행본이 아니라 설치본이다.

```bash
./scripts/install.sh
```

- Release 빌드 → 서명 확인 → 실행 중인 Tokta 종료 → `/Applications/Tokta.app`에 설치 → 실행.
- 빌드 번호(`CFBundleVersion`)는 **커밋 수**다. 설정 → 일반의 “버전 0.1.0 (빌드 N)”으로 어느 커밋을 설치했는지 안다. 커밋하지 않은 변경도 같은 번호로 들어가니 주의.
- Xcode 실행본과 설치본은 번들 ID·데이터 폴더가 같다. 둘을 동시에 켜면 알림이 두 번 온다. 스크립트가 실행 중인 Tokta를 먼저 끈다.
- 서명은 Apple Development 인증서라 `spctl` 평가는 거부(rejected)로 나온다. 이 Mac에서 직접 빌드한 앱은 격리 표시가 없어 그대로 실행된다. 다른 Mac에 줄 때만 Developer ID 서명·공증이 필요하다.

## 로그인 시 열기

설정 → 일반 → “로그인 시 Tokta 열기”. macOS 로그인 항목(`SMAppService.mainApp`)에 등록한다. 로그인 항목은 앱 위치를 기억하므로 `/Applications`의 설치본에서만 켤 수 있게 했다. 승인이 필요하면 시스템 설정 → 로그인 항목을 여는 버튼이 나온다.

## 명령줄 테스트

서명 없이 돌릴 때:

```bash
xcodebuild -project Tokta.xcodeproj -scheme Tokta -destination 'platform=macOS' -derivedDataPath build CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= test
```

`build/`는 git에 넣지 않는다.

## 나중에 필요한 것

- 위젯: App Group `<팀 ID>.app.tokta.shared` — 앱(`Config/Tokta.entitlements`)과 위젯 확장(`Config/ToktaWidget.entitlements`, 샌드박스)에 같이 넣었다. 팀 ID 접두사라 별도 등록 없이 Release 빌드 통과(2026-10-14). [[2026-10-14 데스크톱 위젯]]
- 다른 Mac 배포: Developer ID 서명 + 공증, 자동 업데이트

## 배포용 빌드 (Developer ID + 공증) — 2026-10-15

- `scripts/release.sh` → `dist/Tokta-<버전>.dmg`. 아카이브 → `scripts/ExportOptions.plist`(developer-id, 자동 서명)로 내보내기 → 앱 zip을 `notarytool`로 공증 → `stapler`로 앱에 공증표 → DMG(앱 + /Applications 바로가기). DMG는 서명하지 않는다(앱에 공증표가 붙어 있어 충분).
- **Developer ID 인증서는 이 Mac 키체인에 없다.** Xcode가 내보낼 때 팀의 클라우드 관리 Developer ID 인증서로 서명한다(`-allowProvisioningUpdates`). 확인: 앱·위젯 모두 `Developer ID Application: <팀 이름> (<팀 ID>)`, Hardened Runtime, App Group·iCloud 권한, Developer ID 프로비저닝 프로필 포함. 공증 전 `spctl`은 “Unnotarized Developer ID”로 거부 — 정상.
- 공증 로그인 정보: 키체인 프로필 `tokta-notary`. 처음 한 번 사용자가 `xcrun notarytool store-credentials tokta-notary --apple-id … --team-id <팀 ID>`(앱 전용 암호). **아직 없음.**
- `dist/`는 git에 넣지 않는다.
