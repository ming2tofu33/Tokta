# 앱 구조

SwiftUI, macOS 15 이상, Swift 6. `LSUIElement`로 Dock 아이콘 없이 메뉴바에만 뜬다. App Store 샌드박스는 쓰지 않는다(Codex 실행 파일을 직접 실행해야 해서).

## 데이터 흐름

`UsageStore.refreshAll()` → 계정마다 `ProviderRegistry`에서 서비스 수집기를 찾아 동시에 `fetchUsage` → 성공하면 스냅샷 저장, 실패하면 **마지막 값은 남기고 오류만 표시**.

## 지금 쓸 계정 추천

계정마다 가장 빠듯한 구간(남은 비율이 가장 작은 구간)을 고르고, 그 값이 가장 큰 계정을 추천한다. 예: 5시간 70%·주간 77%인 계정(70)보다 5시간 88%·주간 74%인 계정(74)이 낫다. 다 쓴 계정과 아직 조회 전인 계정은 뺀다. 계정이 2개 이상인 서비스에서만 표시한다. 메뉴에서는 맨 위 카드(`NowPick`)가 보여준다 — [[2026-10-14 지금 쓸 계정 카드]].

**값이 오래됐거나(15분 넘음) 오류가 붙은 계정도 뺀다**(2026-10-13 보정). 오류에는 로그인 풀림, 별칭 이메일과 다른 계정으로 로그인, 이미 추가한 계정과 같은 로그인이 들어간다. 마지막으로 읽은 값이 남아 있어도 지금 그 계정을 쓸 수 있다는 보장이 없어서다. 한도 알림 끝의 “→ 다른 계정 N% 남았어요”도 같은 기준이다. 메뉴바 아이콘 숫자·색(`tightestRemaining`)은 아직 이 기준을 따르지 않는다.

## 카드와 메뉴바

- 계정은 메뉴에서 한 줄로 보이고 ▸로 펼친다. 줄 구성과 색 기준은 [[2026-10-13 메뉴 컴팩트 레이아웃]].
- 줄을 누르면 펼친다. 서비스(`Service.homeURL`)는 펼친 화면 링크나 오른쪽 클릭으로 연다. 오른쪽 클릭: 서비스 열기, 사용량 페이지 열기(`usageURL`), 지금 새로고침, 다시 로그인. 브라우저에 어느 계정으로 로그인돼 있는지는 Tokta가 고를 수 없다. 그래서 “이 계정으로 열기”는 브라우저 대신 Tokta 창이나 터미널로 연다 — [[2026-10-13 계정 바로 쓰기]].
- 마지막으로 읽은 값이 **15분**(`UsageSnapshot.staleAfter`, 자동 갱신 몇 번이 실패해야 넘는 시간)보다 오래되면 막대를 흐리게 하고 “N시간 전 값 · 최신이 아닐 수 있어요”를 붙인다. 1분마다 다시 그린다.
- 계정 이름은 설정 → 계정에서 바로 고친다. 비워두면 메뉴·알림에 “이름 없음”.
- 메뉴바 아이콘 옆 숫자: 서비스마다 가장 여유 있는 계정의 남은 비율 중 가장 작은 값(`AlertPlanner.tightestRemaining`). 아이콘 색과 같은 기준. 설정 → 일반에서 끌 수 있다(기본 켬, `UserDefaults` `menuBarShowsPercent`).

## 계정과 이메일 확인

계정에 이메일이 적혀 있는데 실제 로그인 계정이 다르면 숫자를 붙이지 않고 경고를 띄운다. 다른 계정 사용량이 잘못 붙는 것을 막는다. 웹 로그인으로 처음 연결할 때 이메일이 비어 있으면 로그인한 계정의 이메일로 묶는다.
