# 저장 데이터와 이전

## 위치

`~/Library/Application Support/Tokta/`

| 파일 | 내용 |
|---|---|
| `accounts.json` | 계정 목록 (서비스, 별칭, 이메일, 그룹 ID, 기본 로그인 여부, 구독료·결제일) |
| `groups.json` | 그룹 목록과 순서 |
| `alerts.json` | 알림 설정, “이미 알린 기준선”, 보낸 소진 예측 알림 |
| `history.json` | 계정 × 구간별 사용 기록(8일) |
| `codex/<계정 ID>/` | ChatGPT 전용 로그인 계정의 Codex 로그인 폴더 |
| `grok/<계정 ID>/` | Grok 전용 로그인 계정의 Grok CLI 로그인 폴더 |

- Claude 로그인 쿠키는 WebKit 계정별 저장소에 있다. ChatGPT 전용 로그인 계정의 토큰은 `codex/<계정 ID>/auth.json`에 있고(폴더 권한 700), 만들고 갱신하는 것은 Codex가 한다. Grok 전용 계정 토큰은 `grok/<계정 ID>/auth.json`(Grok CLI가 만들고 갱신). Tokta는 Codex 토큰은 다루지 않고, Grok은 사용량 조회에 `key`만 읽는다. Cursor 로그인 쿠키는 Claude와 같이 WebKit 계정별 저장소.
- 화면의 최신 숫자는 실행할 때마다 다시 읽는다. 추이·예측용 사용 비율 기록만 `history.json`에 8일 남긴다.

## 옛 데이터 이전

[[2026-10-13 서비스를 ChatGPT와 Claude 두 개로 정리]]에 따라 읽을 때 자동으로 바꾼다.

- `"service": "codex"` → ChatGPT
- 지원하지 않는 서비스(`claudeCode` 등) 계정은 빼고 나머지만 읽는다. 한 계정 때문에 전체 목록을 잃지 않게 계정별로 따로 해석한다.
- 그룹 기능 이전 계정은 `groupID`가 없어 “그룹 없음”으로 읽힌다.
