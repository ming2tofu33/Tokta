# 00 서비스 목차

Tokta가 읽는 바깥 서비스마다 노트 하나. 모두 비공식 경로라 언제든 바뀐다. 우리 코드 구조는 [[00 기술 문서 목차]]에 있다.

| 서비스 | 상태 | 수집 방식 | 마지막 확인 |
|---|---|---|---|
| [[ChatGPT]] | 지원 (다중 계정) | Codex `app-server` RPC | 2026-10-13 실제 조회 |
| [[Claude]] | 지원 (다중 계정) | 계정별 웹 로그인 | 2026-10-13 사용자 로그인 |
| [[Grok]] | 지원 (다중 계정) | 공식 Grok CLI 로그인 + xAI 사용량 API | 2026-10-13 실제 조회 |
| [[Cursor]] | 지원 (다중 계정) | 계정별 cursor.com 웹 로그인 | 2026-10-13 사용자 로그인 |
| Grok Bot | 지원 (Cursor 계정에 딸려 저절로) — [[Cursor#Grok Bot]] | 연결된 Cursor 계정의 cursor.com 로그인 | 2026-10-15 실제 조회 |
| [[Antigravity]] | 지원 (계정 하나) · Gemini·Claude·GPT 그룹 한도 | Antigravity CLI `agy -p /usage` | 2026-10-14 실제 조회 |
| [[Gemini]] | Antigravity로 대체 (개인 Gemini CLI 종료) | — | 2026-10-14 |

## 서비스 노트에 적는 것

1. 표: 지원 상태, 수집 방식, 마지막 확인, 코드 위치
2. 무엇을 보여주나 (그 숫자가 실제로 어떤 한도인지)
3. 플랜별 한도 규칙 — 직접 확인한 것과 외부 설명을 구분
4. 수집 순서
5. 응답 형식 확인 이력 — 날짜, 계정·플랜, 확인 방법
6. 깨짐 기록 링크 → `01_Logs/Incidents`

서비스 쪽이 바뀌어 수집이 깨지면 [[00 깨짐 기록 목차]]에 기록하고 해당 서비스 노트의 이력에 한 줄 추가한다.
