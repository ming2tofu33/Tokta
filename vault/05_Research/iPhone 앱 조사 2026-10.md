# iPhone 앱 조사 2026-10

배경: 사용자 “데스크탑에서 보이는 내용을 폰으로도 확인할 수가 있나?”, “맥이 꺼져 있다면 핸드폰으로는 볼 수가 없는 건가?” → 세 단계 제안 → “단계 순서대로 알아봐줘”. **조사만 했고 코드는 아직 없다.**

## 1단계 — 맥이 읽고, iCloud로 폰에 보내기 + 리셋 시각 추정

| 확인한 것 | 결과 |
|---|---|
| 개발 환경 | Xcode 27.0, iOS 27 SDK·시뮬레이터 있음(iPhone 17 시뮬레이터 실행 중) |
| 서명 | 개발 팀의 Apple Development 인증서 2개. 실제 iPhone 설치는 팀 계정이라 1년 유지 |
| 보낼 데이터 | 위젯용 `WidgetData`가 그대로 쓸 만하다: 계정 이름, 플랜, 남은 %, 구간별 막대·색 단계, 추천, 표정, 읽은 시각. **이메일·토큰은 없다.** 리셋 시각은 아직 없음 → 추가 필요 |
| 공용 코드 | `Shared/`의 캐릭터·색 코드가 AppKit(`NSColor`, `NSImage`)에 묶여 있다(16곳). iPhone에서 쓰려면 SwiftUI `Color` 기반으로 손봐야 한다 |

동기화 방법 비교:

| 방법 | 장점 | 단점 |
|---|---|---|
| **CloudKit 개인 DB** (추천) | 본인 iCloud 안에만 저장, 서버 없음. 맥이 올리면 조용한 푸시로 폰 앱·위젯을 깨울 수 있다 | Apple Developer 포털에 iCloud 컨테이너를 등록해야 한다(Xcode 자동 서명이 등록). 맥 앱에도 iCloud 권한 → 프로비저닝 프로필이 붙는다 |
| iCloud Drive 파일 | 맥 쪽은 권한 없이 파일만 쓰면 된다 | 폰은 폴더 접근을 한 번 직접 골라줘야 하고, 동기화가 느리며 위젯이 직접 읽기 어렵다 |

리셋 시각 추정(맥이 꺼져 있을 때): 마지막 값에 구간별 리셋 시각을 같이 보내면, 폰이 리셋 시각이 지난 구간을 “다시 찼을 거예요(추정)”로 보여주고 리셋 알림을 직접 예약할 수 있다. 맥 없이도 “어느 계정이 다시 찼나”는 꽤 정확하다. 남은 %는 맥이 꺼진 뒤 쓴 만큼 틀릴 수 있다.

## 2단계 — 폰이 Claude·Cursor·Grok Bot을 직접 읽기

- 맥의 방식(계정별 WebKit 저장소 + 숨은 웹 보기에서 사이트 안 `fetch`)은 iOS WebKit에서도 같은 구조로 된다.
- 계정마다 폰에서 한 번 로그인 필요. Google 로그인은 앱 안 창에서 막히는 건 같다([[Google 로그인 제약]]).
- iOS는 백그라운드에서 자주 못 돈다. 주로 **앱을 열 때** 읽는다(백그라운드 새로고침은 iOS 마음대로, 보통 몇 시간 간격).
- 확인 전: Claude·Cursor가 iPhone WebKit에서 보안 확인(Cloudflare)을 더 자주 띄우는지.

## 3단계 — ChatGPT·Grok을 웹 로그인으로 읽기

| 서비스 | 찾은 것 | 판단 |
|---|---|---|
| ChatGPT (Codex 한도) | 공식 Codex CLI가 쓰는 `GET https://chatgpt.com/backend-api/wham/usage`(Bearer 토큰). 5시간·주간 사용 %와 리셋 시각. 리셋 남은 횟수는 `wham/rate-limit-reset-credits`. 출처: CodexBar 문서, openai/codex 이슈 | **가능성 높음.** 웹 로그인 세션에서 토큰을 받아 같은 주소를 부르면 맥과 같은 숫자. 문서 없는 주소라 바뀔 수 있다. ChatGPT의 Google·Apple 로그인은 앱 안 창에서 막힐 수 있어 이메일 로그인 필요 |
| Grok | grok.com 페이지에서 `POST /rest/rate-limits`(`requestKind`, `modelName`) → 남은 질문 수 / 전체 / 구간 길이(예: 2시간 25회). 출처: Greasy Fork 스크립트 토론, Chrome 확장 | **다른 숫자다.** 맥이 보여주는 건 xAI 통합 구독의 **주간 크레딧 %**, 웹은 **모델별 질문 수(2시간 단위)**. 폰에서 같은 숫자를 보려면 확인이 더 필요 |
| Antigravity | CLI(`agy /usage`)에만 있음 | 폰 직접 읽기 어려움 |

## 정리

- 1단계는 막힌 게 없다. 결정할 것: **Apple Developer 포털에 iCloud 컨테이너 등록**(예: `iCloud.app.tokta`)과 iPhone 앱 번들 ID.
- 2단계는 1단계 뒤에, Claude 계정이 많아 효과가 크다.
- 3단계는 ChatGPT만 해볼 만하고, Grok은 숫자 종류가 달라 보류.
